Design a URL Shortener (TinyURL)
TIMER
14:52
1. Functional & Non-Functional Requirements
✔ Given a long URL, generate a short 7-character unique alias
✔ Redirecting from short alias to original URL in < 20ms
✔ Read-to-Write Ratio: 100:1 (Heavy Read Intensive System)
✔ High Availability (99.99%) prioritized over immediate consistency
2. Capacity Estimations
Writes: 100M new URLs/month (40 writes/sec)
Reads: 10B redirects/month (4,000 reads/sec)
3. Key Architectural Decisions
Encoding: Base62 vs MD5 Hashing
62^7 = ~3.5 Trillion combinations. Use Key Generation Service (KGS) to pre-generate tokens without hash collisions.
Storage & Caching Layer
NoSQL Key-Value Store (DynamoDB/Cassandra) + Redis LRU cache for the top 20% hot URLs (80/20 Pareto rule).
