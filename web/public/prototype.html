Production Outages

Real-World Incident Deconstructions

AWS-OUTAGE-2017-02-28 HISTORIC CASE

The Amazon S3 Cascading Dependency Failure

An engineer executed a routine debugging command intending to remove a small number of servers from an S3 subsystem in us-east-1. A command typo removed more capacity than intended, causing a cold restart of the entire indexing tier.

09:37 PST: Command executed with typo; removed primary index nodes.
09:42 PST: S3 indexing tier rebooted; metadata cache cold.
10:15 PST: Cascading timeouts hit EC2, EBS, and downstream AWS consoles.
13:54 PST: S3 fully restored after gradual rate-limited warming.
Architectural Takeaway:

Never allow circular boot dependencies. Critical services must be partitioned into blast-radius cells with safe rate limits on administrative operations.

Decision Framework

Trade-Off Battle Arena

Select Production Workload:
Winner for this scenario: Apache Kafka
• Why: Kafka's append-only commit log on disk allows zero-copy sequential I/O to sustain millions of writes per second with consumer replay.
• Why not RabbitMQ: RabbitMQ stores messages in RAM queue buffers; large backlogs degrade broker memory performance.
Wire Protocols

Protocol Packet Inspector

TCP 3-Way Handshake Sequence 1 RTT Total
1. Client → Server: SYN [Seq=0] RTT: 0ms
2. Server → Client: SYN-ACK [Seq=0, Ack=1] RTT: 25ms
3. Client → Server: ACK [Seq=1, Ack=1] RTT: 50ms (ESTABLISHED)
Why this matters: Every new TCP connection costs 1 full round-trip time (RTT). Connection pooling and HTTP keep-alive avoid repeating this handshake for every request.
Implementation

Code-to-Architecture Linker

LUA (ATOMIC REDIS SCRIPT) 
local key = KEYS[1]
local capacity = tonumber(ARGV[1])
local rate = tonumber(ARGV[2])
local now = tonumber(ARGV[3])

local data = redis.call('HMGET', key, 'tokens', 'last_time')
local tokens = tonumber(data[1]) or capacity
local last_time = tonumber(data[2]) or now

-- Replenish tokens based on elapsed seconds
local delta = math.max(0, now - last_time)
tokens = math.min(capacity, tokens + delta * rate)

if tokens >= 1 then
    tokens = tokens - 1
    redis.call('HMSET', key, 'tokens', tokens, 'last_time', now)
    return 1 -- Allowed
else
    return 0 -- Throttled (HTTP 429)
end
Literature

Seminal Systems Papers

Google File System (GFS) Ghemawat et al., 2003

The Breakthrough: Embraced commodity server failures as the norm. Single Master with massive 64MB chunks and append-only operations eliminated complex random-write locks.

Key takeaway: Append-only consistency outperforms in-place updates.
Amazon Dynamo DeCandia et al., 2007

The Breakthrough: Prioritized shopping cart availability over consistency (AP system). Introduced consistent hashing with virtual nodes and vector clocks for concurrent write reconciliation.

Key takeaway: Always-writable carts via eventual consistency.
Raft Consensus Ongaro & Ousterhout, 2014

The Breakthrough: Replaced incomprehensible Multi-Paxos with an understandable state machine based on explicit leader election and log replication invariants.

Key takeaway: Strong leader election reduces state machine complexity.
